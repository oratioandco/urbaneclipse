## Set up the new machine

```bash
git clone https://github.com/oratioandco/urbaneclipse.git
cd urbaneclipse
nvm install 22 && nvm use 22      # .nvmrc says 22; Astro refuses Node 20
npm ci
npx vitest run                    # expect 588 passed, 1 skipped
npm run build
```

- **`.env`** (gitignored, copy it across by hand, never commit it): `PUBLIC_CESIUM_ION_TOKEN`,
  `PUBLIC_TILESET_URL`.
- **Python tools** (`scripts/*.py`, Python 3.14 here): `python3 -m venv .venv && .venv/bin/pip install -r scripts/requirements.txt`.
- **Deploying** needs the `coolify` CLI logged in to the Coolify instance (its token lives in the
  CLI's own config, not in this repo) and, for city data uploads, the Hetzner SSH key. Steps:
  push `main`, then `coolify deploy uuid dcqd5hrcyrnfnlvqmhk4et6r` (add `--context cax21` if the
  CLI has more than one context). Pushing alone does not build. Check the live bundle afterwards.
  Only deploy with Tobias's OK.

## Gotchas worth knowing

- **Verify before claiming.** Diff + green tests, and for UI a screenshot of the real page.
  Output from other agents (qwen via codeaf) has shipped tests against invented APIs before.
- **Positions from data, never from memory.** OSM (Overpass/Nominatim) for coordinates, DGM1/DOM1
  for heights. Write the independent check into the test comment.
- **Headless checks of `/classic`:** Cesium keeps the page busy, so Playwright's actionability
  waits time out. Click via `page.evaluate`, remove the canvases, capture with CDP
  `Page.captureScreenshot`. `/plan/` never fires `load` locally (city data is server-only):
  wait for `domcontentloaded`.
- **Typecheck:** bare `tsc` reports hundreds of environmental errors (JSX flag). Use
  `npx tsc --noEmit -p . --jsx react-jsx` and compare touched files before/after.
- **Worktrees** `../urbaneclipse-miniature` and `../urbaneclipse-miniature-dom` on the old Mac hold
  nothing that is not on GitHub (only a duplicate fixture and codeaf/research scratch). Retire
  them with `git worktree remove` once the new machine is verified.
